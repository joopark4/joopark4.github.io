## Sum-Thumb 1.6.0

### 개선 사항
- 자막 생성 및 분석 중 즉시 중단 가능한 취소 버튼 추가
- 폴더 일괄 처리 중에도 즉시 취소 지원 (자막/분석 모두)
- 오디오 추출 중 발생하던 크래시 수정
- Qwen3-ASR 대용량 오디오 처리 시 메모리 최적화
- 자동 업데이트 안정성 향상

### 버그 수정
- AVAssetWriter 상태 검사 누락으로 인한 크래시 수정
- 취소 시 부분 자막이 정상 결과로 저장되던 문제 수정
- 분석 취소 시 이전 결과가 덮어써지던 문제 수정
- 동시성 데이터 레이스 문제 해결
