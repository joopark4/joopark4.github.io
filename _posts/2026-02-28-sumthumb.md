## 💡 프로젝트 소개 (Overview)
**SumThumb**은 영상/음성 파일에서 **On-Device AI(WhisperKit / Qwen3-ASR)로 자막을 생성**하고, **Cloud AI(Gemini / OpenAI) 혹은 Local AI(Qwen3-4B / Ollama)로 콘텐츠를 분석**하는 macOS 네이티브 앱입니다.

**SumThumb** is a macOS native application that generates subtitles from media files using **On-Device AI (WhisperKit / Qwen3-ASR)** and analyzes content via **Cloud AI (Gemini / OpenAI) or Local AI (Qwen3-4B / Ollama)**.

- **지원 환경 (Supported Environments):** macOS 15+ / Apple Silicon 전용 (Native Swift 6 & SwiftUI 기반)
- **자막 생성 (Subtitle Generation):** 오프라인 환경에서 미디어(.mp4, .mov, .mp3, .m4a, .wav)를 드래그 앤 드롭하여 빠르게 자막(.srt, .vtt)을 추출하고 손쉽게 저장합니다. (Drag and drop media to quickly extract subtitles offline.)
- **콘텐츠 분석 (Content Analysis):** 추출된 텍스트를 AI로 분석하여 3줄 요약, 유튜브 제목 추천 5선, 해시태그 40개, 썸네일 이미지 프롬프트를 자동 생성합니다. (AI automatically generates a 3-line summary, 5 YouTube titles, 40 tags, and thumbnail image prompts.)

### ⚙️ 핵심 기능 (Key Features)
- **온디바이스 STT 엔진 (On-Device STT):** WhisperKit (CoreML 기반 Whisper) 및 Qwen3-ASR (MLX 기반, 52개 국어 지원) 지원
- **로컬 AI (Local LLM):** API 키가 필요 없는 완전 오프라인 MLX (Qwen3-4B) 및 직접 구축한 Ollama 로컬 서버 모델 연동
- **클라우드 고성능 AI (Cloud AI):** Google Gemini, OpenAI 등 API Key로 직접 연동
- **폴더 일괄 처리 (Batch Processing):** 다수의 미디어 파일을 폴더 단위로 일괄 처리하여 자막 추출(.srt) 및 콘텐츠 분석 결과물(.md) 자동 생성

## 🛠 설치 및 실행 방법 가이드
1. 위 링크 또는 [Releases(저장소)] 링크에 업로드된 `SumThumb-1.5.1.dmg` 확장자 파일을 맥으로 다운로드합니다.
2. 다운로드가 완료된 파일을 마우스로 더블 클릭하여 디스크 이미지를 마운트합니다.
3. 팝업 창이 열리면, **SumThumb.app 아이콘**을 우측의 **Applications(응용 프로그램)** 폴더 아이콘으로 드래그 앤 드롭합니다.
4. 응용 프로그램 폴더에 복사(설치)된 앱을 실행합니다.
