## 💡 데스크톱 위에 살아 숨 쉬는 나만의 AI 아바타, AMA

**AMA (AI My Avatar)**는 화면 위를 자유롭게 이동하며 사용자와 대화할 수 있는 **macOS 전용 3D 아바타 AI 데스크톱 앱**입니다. 
딱딱한 채팅창을 벗어나, 내가 직접 선택한 귀여운 아바타(`.vrm`)와 텍스트나 음성으로 자연스럽게 대화해보세요!

🔗 **[GitHub Repository 바로가기 (소스코드 및 상세 가이드)](https://github.com/joopark4/AMA)**

### 🎬 AMA 데모 영상

아래 데모 영상은 AMA 아바타가 **Claude Code Channels**와 연결된 상태에서, 사용자 요청을 받아 터미널 작업 결과를 다시 대화와 음성 형태로 전달하며 **양방향으로 상호작용**하는 모습을 보여줍니다.

현재 공개된 데모는 Claude Code 연동 예시이지만, AMA는 README 기준으로 **OpenAI Codex CLI 연동도 공식 지원**합니다. 즉, 개발자라면 취향과 작업 방식에 따라 Claude 계열 워크플로우뿐 아니라 Codex 기반 코딩 에이전트와도 AMA 아바타를 연결해 사용할 수 있습니다.

### ✨ 주요 특징 및 기능
- **자유로운 아바타 위치 이동:** 마우스로 아바타를 드래그해 화면 어디에든 둘 수 있고, 대화 말풍선이 아바타 상단에 자연스럽게 표시되어 더욱 생동감 있게 느껴집니다.
- **편리한 글로벌 음성 단축키:** 앱이 화면 뒤에 가려져 있더라도 `Cmd + Shift + Space` 키를 누르면 바로 음성으로 말을 걸고 대화를 종료할 수 있습니다. 
- **오프라인 STT/TTS 완벽 지원:** 인터넷 연결 없이도 내 말을 알아듣는 고성능 음성 인식 엔진(Whisper)과 사람처럼 대답해 주는 자연스러운 음성 합성(Supertonic) 기능이 앱 내에 기본 내장되어 있습니다.
- **프라이버시 완벽 보호 (로컬 AI):** 내 컴퓨터 자원만으로 동작하는 [Ollama](https://ollama.com/) 서버를 연결하면, 대화 내용이 외부 서버로 전혀 전송되지 않아 완벽하게 프라이버시가 보호됩니다.
- **최고 성능의 클라우드 AI 지원:** [Google Gemini](https://aistudio.google.com/app/apikey), [OpenAI](https://platform.openai.com/api-keys), [Claude](https://console.anthropic.com/) 공식 API 키를 등록하여 세계 최고 수준의 초거대 AI와 대화할 수도 있습니다. 
- **개발자용 코딩 에이전트 연동 지원:** `Claude Code Channels`는 물론이고 `OpenAI Codex CLI`까지 지원하여, 내 코드를 분석·수정·실행하는 과정을 아바타와 양방향 대화 형태로 이어갈 수 있습니다.

## 📥 다운로드 및 설치 가이드

현재 최신 릴리스 버전은 아래 링크에서 다운로드할 수 있습니다. (Apple Silicon M1/M2/M3/M4 이상 Mac 권장)

📦 **[AMA 최신 버전 다운로드 (Github Releases)](https://github.com/joopark4/AMA/releases/latest)**

### 💻 설치 및 최초 실행 방법
1. 위 링크에서 `AMA_x.x.x_aarch64.dmg` 식의 데스크톱 앱 설치 파일을 다운로드합니다.
2. 다운로드 된 DMG 파일을 클릭하여 실행하고, 창이 열리면 **AMA 앱 아이콘**을 **Applications(응용 프로그램)** 폴더로 드래그 앤 드롭합니다.
3. 응용 프로그램 폴더에서 AMA 앱을 찾아 더블 클릭해 실행합니다.
4. **최초 실행 시:** 고품질 음성 처리 및 아바타 구동을 위한 필수 데이터를 최초 1회 자동으로 다운로드합니다.
5. 안내에 따라 아바타 이름을 정하고, 기본 아바타를 로드하면 대화 준비가 완료됩니다!

> **🚨 앱이 열리지 않는 경우 (Gatekeeper 보안 안내):**  
> Mac의 자체적인 샌드박스 정책으로 인해 처음 실행 시 "확인되지 않은 개발자의 앱" 경고가 나타나며 열리지 않을 수 있습니다. 
> 이 경우 Mac의 **[시스템 설정] -> [개인정보 보호 및 보안]** 메뉴 하단으로 스크롤하여 **'확인 없이 허용(Open Anyway)'** 버튼을 눌러주시면 정상 실행됩니다.

## 🧠 맞춤형 AI 연결하기 (사용자 가이드)

AMA 아바타가 어떤 지능(엔진)으로 대답할지 직접 선택할 수 있습니다. 화면 우하단의 **설정(⚙️) > AI 탭**에서 원하는 방식을 고르세요.

### 🟢 추천 1: 무료/내장형 로컬 AI (Ollama 연동)
개인정보 유출 걱정 없이 무료로 사용하고 싶다면 내 컴퓨터 자원을 사용하는 이 방식을 추천합니다.
1. [Ollama 공식 홈페이지](https://ollama.com/)에서 Mac 버전을 설치합니다.
2. 터미널(Terminal) 앱을 열고 언어 모델을 하나 다운로드합니다. (예: `ollama pull deepseek-r1:8b`)
3. 다운로드가 완료되면 터미널에 `ollama serve`를 켜둔 상태로 AMA 설정창에 진입합니다.
   - **LLM Provider:** `ollama`
   - **Endpoint:** `http://localhost:11434`
   - **Model:** 다운받은 모델명 (예: `deepseek-r1:8b`)

### 🔵 추천 2: 아주 똑똑한 클라우드형 (Google Gemini 등)
개인 컴퓨터의 팬 소음이나 배터리 소모 없이 빠르고 가장 똑똑한 답변을 원한다면 이 방식을 추천합니다.
1. [Google AI Studio](https://aistudio.google.com/app/apikey)에서 개발자용 무료 API 키를 발급받습니다.
2. AMA 설정창에서 아래와 같이 입력합니다.
   - **LLM Provider:** `gemini`
   - **Model:** `gemini-2.0-flash`
   - **API Key:** 방금 발급받은 키를 정확히 복사해 붙여넣습니다.

*(ChatGPT를 서비스하는 OpenAI나 Claude를 제공하는 Anthropic의 API를 사용하는 것도 마찬가지 방식으로 지원됩니다.)*

### 🤖 추가 기능: Claude Code Channels 지원 (개발자/파워 유저용)
AMA 아바타를 Anthropic의 [Claude Code](https://docs.anthropic.com/en/docs/claude-code) Channels 기능과 바로 연결하여, 개발 도구와 양방향으로 대화할 수 있습니다!
1. 터미널 환경에 익숙하시다면 우선 시스템에 `Node.js` 18 버전 이상과 Claude Code CLI를 설치해 주세요. (`npm install -g @anthropic-ai/claude-code`)
2. 터미널에서 `claude login` 명령어로 계정을 연결합니다.
3. AMA 앱을 켜고 **설정 > Claude Code Channels 탭**에서 토글을 켭니다. (이때 필요한 브릿지 설정이 자동으로 적용됩니다.)
4. 별도 터미널 창을 열고 아래 명령어를 실행해 통신을 활성화합니다.
   ```bash
   claude --dangerously-load-development-channels server:ama-bridge --permission-mode bypassPermissions
   ```
5. 최초 권한 확인 시 `Yes`를 선택하면 연동이 완료됩니다. 이제 AMA에서 편하게 질문하면, Claude Code가 터미널 작업을 수행/분석하여 응답하고, 아바타가 그 내용을 육성(TTS)으로 대답합니다!

*(안내: 이 기능은 실험적인 리서치 프리뷰 형태입니다. 자동 도구 실행 권한이 주어지므로 반드시 안전한 로컬 환경에서만 사용하세요. 토글을 끄면 원래 세팅해두었던 기본 AI 모델로 즉시 복귀됩니다.)*

### 🧑‍💻 추가 기능: OpenAI Codex CLI 지원 (개발자/파워 유저용)
AMA는 이제 [OpenAI Codex CLI](https://github.com/openai/codex)와도 연동됩니다. 별도 채널 서버를 직접 띄우는 방식이 아니라, AMA 안에서 `LLM Provider`를 `Codex`로 고르면 설치 및 로그인 상태를 자동으로 확인하고 바로 연결할 수 있는 흐름입니다.

1. 먼저 터미널에 Codex CLI를 설치합니다. (`npm install -g @openai/codex`)
2. 이어서 `codex login` 명령어로 로그인까지 마칩니다.
3. AMA 앱을 실행한 뒤 **설정 > LLM Provider**에서 `Codex`를 선택합니다.
4. 연결이 확인되면 아래 항목들을 추가로 조정할 수 있습니다.
   - **작업 폴더:** Codex가 실제로 코드를 읽고 쓸 디렉터리 (기본값은 `~/Documents`)
   - **모델 선택:** 연결 후 사용 가능한 Codex 모델 목록 중 선택
   - **추론 성능:** `Low / Medium / High / Extra High`
   - **접근 권한:** 요청 시 승인(기본), 자동 승인 등 작업 스타일에 맞는 권한 정책 설정
5. 이후에는 AMA에 말을 걸면 Codex가 백그라운드에서 코딩 작업을 수행하고, 그 결과를 다시 아바타가 자연스러운 음성과 대화 형태로 전달해줍니다.

Codex 연동 시에는 CLI가 내부적으로 `codex app-server`를 자동 실행하므로, Claude Code Channels처럼 별도 브릿지 서버를 직접 띄울 필요가 없다는 점도 꽤 편리합니다.

> **⚠️ 주의:** 접근 권한을 `자동 승인`으로 두면 Codex가 파일 수정이나 명령 실행을 더 적극적으로 수행할 수 있으므로, 반드시 신뢰할 수 있는 로컬 개발 환경에서만 사용하는 것을 권장합니다. 다른 AI Provider로 전환하면 Codex 연결은 자동으로 종료됩니다.

## 🩱 나만의 3D 아바타 파일(.vrm) 적용하기

이 앱은 확장자가 `.vrm`으로 끝나는 3D 캐릭터 모델 규격을 지원합니다. 화면 우측 하단의 **설정 > 아바타 탭**에서 `.vrm` 파일을 선택하면 언제든지 아바타를 바꿀 수 있습니다.

**아바타를 구할 수 있는 추천 사이트:**
- [VRoid Hub](https://hub.vroid.com/en/): 다른 창작자가 다운로드를 허용한 귀여운 모델을 공유받을 수 있습니다.
- [BOOTH (VRM 카테고리)](https://booth.pm/en/search/VRM): 고퀄리티 유/무료 아바타 파일들이 활발히 거래되는 마켓입니다.
- [VRoid Studio](https://vroid.com/en/studio/): 직접 그림을 그리듯 나만의 3D 아바타를 무료로 제작하고 `.vrm`으로 내보낼 수 있는 놀라운 툴입니다.

> **⚠️ 타인 아바타 사용 시 주의사항:**  
> 어떤 `.vrm` 캐릭터를 사용하실 때에는, 해당 캐릭터의 상업적 이용 가능 여부, 방송이나 영상 업로드 허용 여부, 2차 개조(수정) 허용 범위 등 **원작자의 이용 라이선스를 반드시 확인**하고 사용하시기 바랍니다.
