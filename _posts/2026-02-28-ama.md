## 💡 프로젝트 소개 (Overview)
**AMA (AI My Avatar)**는 기존 MyPartnerAI에서 이름이 변경되고 성능이 더욱 개선된 나만의 3D 인공지능 비서 앱입니다. 자신이 원하는 모습의 3D 아바타(.vrm)를 불러와 자연스럽게 대화할 수 있습니다. 

**AMA (AI My Avatar)** is your personal 3D AI assistant app, evolved from MyPartnerAI with significantly improved performance. Load your favorite 3D avatar (.vrm) and enjoy natural conversations.

### 🧠 지원 AI 모델 (Supported LLM Providers)
- **로컬 모델 (Local AI):** [Ollama](https://ollama.com/) 서버를 통해 컴퓨터 자원만으로 완벽하게 프라이버시가 보호되는 로컬 추론을 지원합니다. (Ollama, LocalAI support for 100% private execution)
- **클라우드 모델 (Cloud AI):** [Google Gemini](https://aistudio.google.com/app/apikey), [OpenAI](https://platform.openai.com/api-keys), [Anthropic Claude](https://console.anthropic.com/) 공식 API Key를 등록하여 고성능 클라우드 언어 모델을 사용할 수 있습니다. (Cloud support for Gemini, OpenAI, Claude via API keys)

### 🎙️ 음성 엔진 런타임 (Speech & TTS Engine)
- 로컬 마이크를 통해 사용자의 음성을 오프라인으로 인식(STT)하도록 [whisper.cpp](https://github.com/ggml-org/whisper.cpp) 기반 변환 엔진 모델(`base`, `small`, `medium`)을 내장/지원합니다. (Offline Speech-to-text with whisper.cpp)
- ONNX 런타임 상에서 [Supertonic](https://github.com/supertone-inc/supertonic) 기반 오프라인 모델을 활용하여 생성된 답변을 자연스러운 TTS(Text-to-Speech)로 읽어줍니다. (Natural offline text-to-speech with Supertonic models)

### 💻 설치 가이드 (Installation Guide)
1. 위 링크에서 `AMA_v0.5.0.dmg` 백업 파일을 다운로드합니다. (Download the DMG file from the link above.)
2. 다운로드 된 DMG 파일을 더블클릭하여 마운트합니다. (Double-click to mount the DMG file.)
3. 열린 창에서 **AMA 앱 아이콘**을 **Applications(응용 프로그램)** 폴더로 드래그 앤 드롭하여 복사합니다. (Drag and drop the AMA icon into your Applications folder.)
4. 응용 프로그램 폴더에서 앱을 실행하여 사용합니다. (Run the app from the Applications folder.)

### 🚨 앱 첫 실행 시 보안 안내 (Gatekeeper Error Notice)
> Mac의 샌드박스 정책(Gatekeeper)에 의해 최초 실행 시 "확인되지 않은 개발자의 앱" 경고 팝업이 표시되어 열리지 않을 수 있습니다. 
> 이 경우 Mac의 **[시스템 설정] -> [개인정보 보호 및 보안]** 탭 끝으로 스크롤하여 앱 실행을 **'확인 없이 허용(Open Anyway)'** 버튼을 눌러 승인해주시기 바랍니다.
> *(Due to Mac's Gatekeeper security policy, you might see an "unidentified developer" warning on the first run. Please go to **[System Settings] -> [Privacy & Security]**, scroll down, and click **'Open Anyway'** to authorize the app.)*

### 👗 아바타 (VRM) 관련 안내 (Avatar / VRM Notice)
캐릭터 기능을 온전히 활성화하기 위해서는 `.vrm` 확장자로 된 3D 아바타 파일이 필요합니다. 
*(You need a valid `.vrm` 3D avatar file to fully activate the character module.)*
