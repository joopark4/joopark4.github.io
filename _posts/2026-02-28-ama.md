## 💡 프로젝트 소개 (Overview)
**AMA (AI My Avatar)**는 기존 MyPartnerAI에서 이름이 변경되고 성능이 더욱 개선된 나만의 3D 인공지능 친구 앱입니다. 자신이 원하는 모습의 3D 아바타(.vrm)를 불러와 자연스럽게 대화할 수 있습니다. 

**AMA (AI My Avatar)** is your personal 3D AI assistant app, evolved from MyPartnerAI with significantly improved performance. Load your favorite 3D avatar (.vrm) and enjoy natural conversations.

### 🧠 지원 AI 모델 (Supported LLM Providers)
- **로컬 모델 (Local AI):** [Ollama](https://ollama.com/) 서버를 통해 컴퓨터 자원만으로 완벽하게 프라이버시가 보호되는 로컬 추론을 지원합니다. (Ollama, LocalAI support for 100% private execution)
- **클라우드 모델 (Cloud AI):** [Google Gemini](https://aistudio.google.com/app/apikey), [OpenAI](https://platform.openai.com/api-keys), [Anthropic Claude](https://console.anthropic.com/) 공식 API Key를 등록하여 고성능 클라우드 언어 모델을 사용할 수 있습니다. (Cloud support for Gemini, OpenAI, Claude via API keys)

### 🎙️ 음성 엔진 런타임 (Speech & TTS Engine)
- 로컬 마이크를 통해 사용자의 음성을 오프라인으로 인식(STT)하도록 [whisper.cpp](https://github.com/ggml-org/whisper.cpp) 기반 변환 엔진 모델(`base`, `small`, `medium`)을 내장/지원합니다. (Offline Speech-to-text with whisper.cpp)
- ONNX 런타임 상에서 [Supertonic](https://github.com/supertone-inc/supertonic) 기반 오프라인 모델을 활용하여 생성된 답변을 자연스러운 TTS(Text-to-Speech)로 읽어줍니다. (Natural offline text-to-speech with Supertonic models)

# AMA (AI My Avatar) — 시스템 아키텍처 & 데이터 플로우

> Tauri 2 (Rust) + React 18 + Three.js + 로컬 AI 추론

## 기술 스택 요약

| 계층 | 기술 | 역할 |
|------|------|------|
| Desktop Shell | **Tauri 2** | 네이티브 윈도우, IPC, 시스템 권한, 파일 I/O |
| Frontend | **React 18 + TypeScript** | UI 렌더링, 상태 관리, 대화 오케스트레이션 |
| 3D Rendering | **Three.js + React Three Fiber** | WebGL 기반 VRM 아바타 실시간 렌더링 |
| Avatar Runtime | **@pixiv/three-vrm** | VRM 본/표정/물리/SpringBone 제어 |
| State | **Zustand 5** | 5개 스토어, persist 미들웨어로 설정/대화 영속화 |
| STT | **Whisper (whisper-cli)** | Rust에서 로컬 실행, WAV 16kHz mono 입력 |
| TTS | **Supertonic + ONNX Runtime Web** | 브라우저 내 신경망 추론, 10종 음성 스타일 |
| LLM | **Ollama / Claude / OpenAI / Gemini / LocalAI** | 멀티 프로바이더 라우터 패턴 |
| Build | **Vite 6** | HMR 개발 서버 + 프로덕션 번들 |
| Styling | **Tailwind CSS 3** | 유틸리티 기반 UI 스타일링 |
| i18n | **i18next** | 한국어(기본) / 영어 |

## 1. 음성 입력 → STT

```
마이크 입력 (버튼 클릭 / 글로벌 단축키)
    │
    ▼
[원격 세션 감지] ──── 원격이면 차단 + 안내
    │ OK
    ▼
[Whisper 엔진 가용성 확인] ──── 미설치면 설치 안내
    │ OK
    ▼
[마이크 녹음 → PCM → 리샘플링(16kHz) → WAV 인코딩]
    │
    ▼
[Tauri IPC → Rust 백엔드 Whisper 로컬 추론]
  결과: { text, confidence, language }
    │
    ▼
[음성 명령 판별]
  "설정 열어" → 즉시 실행    ←── 앱 제어 명령
  일반 대화  → LLM 추론으로  ←── 대화 흐름
```
